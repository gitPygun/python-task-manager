# Python Task Manager

## About
A simple task management application built with Python that helps users organize and track their daily tasks.

## Features
- Add new tasks
- View existing tasks
- Mark tasks as completed
- Delete tasks

## Technologies Used
- Python

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python3 task_manager.py`
